# PROSAFE-TWIN

*Proactive Real-Time Road Safety Interventions Via Predictive AI-Enabled Digital Twins*

PROSAFE-TWIN develops an AI-enabled hybrid digital twin that combines traffic physics with real-time sensor, vehicle, and weather data to predict and prevent safety-critical road events. The project supports road authorities with uncertainty-aware risk insights, fair safety interventions, and human-in-the-loop decision-making, with validation across diverse European testbeds.
